Empower design system

Review board.

Every component the app is built from, in every state and variant its recipe defines. Read across a row to compare states: the order never changes. The line under a card lists only what that card changes from Default.

What this board proves: each component, state and variant draws from the recipes on this branch, and each readout is read from the recipe or preset that sets it.

What it does not prove: how a component sits in its real screen, motion and timing, behaviour with real data, or contrast over photographs. Hover and Pressed are held still here by a twin class; in the app they follow the pointer.

Surfaces

What each kind of surface is made of. Set once in design_system/surfaces.json; a recipe names one.

State presets

How anything you can press answers. Set once in design_system/states.json; the cards below show each preset on the components that name it.

on-dark

A control drawn on a dark fill: a light veil on hover, a stronger one and a slight shrink when pressed.

hover background-image: linear-gradient(color.state.hover_on_dark, color.state.hover_on_dark) · pressed background-image: linear-gradient(color.state.pressed_on_dark, color.state.pressed_on_dark) · transform: scale(motion.scale.pressed) · used by .btn--secondary, .chip, .choice, .mini-btn

on-light

A control drawn on the white fill: a dark veil on hover, a stronger one and a slight shrink when pressed.

hover background-image: linear-gradient(color.state.hover_on_light, color.state.hover_on_light) · pressed background-image: linear-gradient(color.state.pressed_on_light, color.state.pressed_on_light) · transform: scale(motion.scale.pressed) · used by .btn, .mini-btn--dark, .composer__send

toggle

A control that can be switched on. Off, it answers like a dark control; on, it has turned white, so the veil turns dark.

hover background-image: linear-gradient(color.state.hover_on_dark, color.state.hover_on_dark) · pressed background-image: linear-gradient(color.state.pressed_on_dark, color.state.pressed_on_dark) · transform: scale(motion.scale.pressed) · used by nothing yet

surface

A whole row or panel you can press: the same light veil, and a smaller shrink because the thing is bigger.

hover background-image: linear-gradient(color.state.hover_on_dark, color.state.hover_on_dark) · pressed background-image: linear-gradient(color.state.pressed_on_dark, color.state.pressed_on_dark) · transform: scale(motion.scale.card_pressed) · used by .option, .event-row

text

Quiet text you can press, such as Back or a tab: it brightens to full white on hover and dims while held.

hover color: color.text.primary · pressed opacity: opacity.pressed · used by .back, .composer__cancel, .nav__link

link

A coloured text link: its underline thickens on hover and the text dims while held.

hover text-decoration-thickness: border.width.strong · pressed opacity: opacity.pressed · used by .link, .link-btn, .swipe-card__more

dim

A mark or icon already at full strength, such as the wordmark: it eases back on hover and further while held.

hover opacity: opacity.hover · pressed opacity: opacity.pressed · used by .wordmark, .star, .chat-header__back, .chat-header__who, .voice__play, .people-card__link

card

A card led by artwork, like a Disney tile: it grows a touch on hover and settles back a touch when pressed.

hover transform: scale(motion.scale.hover) · pressed transform: scale(motion.scale.card_pressed) · used by .event-card__link, .featured

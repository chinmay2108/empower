Empower design system

Components.

Everything the app is built from, in every state the product owner signs off: resting, pressed or selected, disabled, focused, empty and in error. Nothing here is styled by hand. Each specimen carries the class you write in markup; the look comes from the token recipe behind it.

Focus states: press Tab to walk this page with the keyboard. Every button, link, chip and field draws the aqua focus ring from the base recipe when it has focus. Nothing on this page is clickable; the links point nowhere on purpose.

Tokens

Raw values live in one file, design_system/tier_00_foundations.json, and nowhere else. Every recipe writes a token name; the build turns it into a CSS variable. These are the names you may use.

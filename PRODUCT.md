# Empower

Empower helps people new to a city choose a local group and return often enough to make friends.

## Platform

web

## Discovery

Three weekly picks lead discovery, one decision at a time. People can browse the wider week before spending a pass. Same-day plans and check-ins retain priority on Home.

## Constraints

The mobile-first site runs from a local HTML file or GitHub Pages. Matching, attendance, and simulated conversations use the existing local data model.
